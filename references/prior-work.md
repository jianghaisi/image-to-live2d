# 已核实的历史操作

记录来自 2026 年 9 月一次实际角色制作，以及后续的应用接入检查。整理时核对了操作记录、分层源文件、工作工程和导出诊断。公开版本保留经验，不包含个人会话编号、电脑路径、原始角色素材或连接凭据。

## 实际路线与最终决定

1. 从 PNG 经 See-Through 得到粗分层 PSD，修正眼白和下装遮挡顺序。
2. 根据 alpha 分离左右眼部、衣袖和鞋等部件；18 层到 24 层的候选曾验证合成不变。不是每张角色图都满足这个拆分前提。
3. 尝试 Cubism FREE 模式导入/网格；用户认为逐项操作太慢，明确希望使用 PSD2Live，并不想再进入 Cubism。
4. PSD2Live 0.6.0 CLI 成功导出 `.cmo3/.moc3/.model3.json`、贴图、物理和 idle/blink/nod/shake 动作。偏侧脸极值过度，曾把 head strength 从 1.0 降为 0.65。
5. MCP 起初未连接成功。修复 Java 临时目录故障后，实际握手并调用工具；随后创建参数/K 帧、道具显隐并保存 `.psd2live` 工程。
6. 挥手虽然触发并有截图，后来发现整袖刚性旋转导致肩部断裂和穿模。作者最终取消挥手，删除运行时动作入口和 wave 文件；未导出后续手臂实验。
7. 后续作品库任务进一步限制该角色的头/身体角度动作，使用呼吸和安全反馈。它是特定模型在特定页面的决定，不代表所有模型都不能转头。

## 保留下来的经验

- 分层 PSD、PSD2Live 工作工程、可编辑 Cubism 工程和运行模型包分别保留，不能互相替代。
- 历史确定性拆层脚本的映射针对原角色，未打包成通用工具；对其他角色应重新检查部件、遮挡和侧别。
- 历史导出诊断包括中性姿态偏差及 CMO3 源编辑链缺失警告。图层、画元或参数数量不能作为质量门槛。
- 接入应用后要核对源包与运行包哈希，避免显示旧版本。

这里保留技术方法，不复制旧角色、截图、第三方程序或连接凭据，也不恢复已经撤销的动作。
