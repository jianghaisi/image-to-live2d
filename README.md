# 图片转 Live2D

一个给 Codex 使用的技能，把静态角色图做成可运行的 Live2D 模型。主要使用开源工具 [PSD2Live](https://github.com/tsunehimatoi/psd2live)，从素材检查、自动生成到模型调整和动作验收，沿用一次实际制作中跑通的方法。

## 它能帮你做什么

有分层 PSD 时，先检查图层，再用 PSD2Live 生成模型。只有 PNG 时，先准备分层和遮挡补画。已经有模型时，优先修正现有文件，不必重做。

交付包括运行模型、贴图，以及实际生成的物理、动作和可编辑工程。眨眼、呼吸等基础动作先验收；复杂表情和挥手需要额外制作，不能保证一键完成。

## 安装和使用

下载或克隆本仓库，将整个 `image-to-live2d` 文件夹放进个人技能目录：

- Windows：`%USERPROFILE%\.codex\skills\image-to-live2d`
- macOS / Linux：`~/.codex/skills/image-to-live2d`

让 Codex 加载这个技能，然后提供角色 PNG、PSD 或现有模型：

> 使用 $image-to-live2d，把这张角色图片做成 Live2D。保留源文件，检查眨眼、呼吸和头发摆动。

本仓库提供操作说明和校验脚本。建模需要另行准备 PSD2Live；图片拆层和补画需要可用的图像工具。PSD2Live 的下载与使用以它自己的项目说明为准。

## 实际步骤

1. 找现有 PSD 或模型，能复用就不重做。
2. 检查图层、透明度、前后遮挡和完整合成图。
3. 用 PSD2Live 自动导出到新的版本目录。
4. 通过 MCP 读取模型，按需要调整参数和部件，保存工程。
5. 检查模型包，再实际播放动作，确认没有断裂、重影或穿模。
6. 交付模型和预览，说明已通过检查的动作及剩余问题。

详细操作见 [SKILL.md](SKILL.md)。

## 我们踩过的坑

- 白眼和腿被遮住：图层顺序错了，先改顺序，不必重绘。
- 书本丢失：源 PSD 已经缺书，不能直接归咎于导入工具。
- 转头变形：偏侧脸不适合直接套大幅度动作，需逐姿态检查。
- MCP 显示在线却连不上：实际端口没有监听，曾通过修复 Java 临时目录解决。
- 修改后保存失败：临时目录与保存目录的加密属性不一致，不能急着重启丢掉工程。
- 挥手能播放但不好看：整条袖子刚性旋转，肩部断裂和穿模，最终撤掉该动作。

记录见 [历史操作与教训](references/prior-work.md)。文件能导出、动作能触发，都不能代替实际效果检查。

## 检查模型包

需要 Python 3.11 或更高版本，无需安装第三方 Python 库：

```sh
python scripts/validate_model.py /path/to/character.model3.json
```

脚本检查文件引用、文件是否齐全、JSON、MOC3 文件头、动作曲线数量和 SHA-256。通过时退出码为 0；有结构错误时为 1。它不会播放模型，也不会判断动作是否自然。
